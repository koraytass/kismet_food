# Implementation Guide for Kismet Foods Landing Page

This document provides instructions for Claude Code or other development tools to build the Kismet Foods landing page based on the generated design.

## 1. Brand Identity & Visual Specs
- **Primary Color:** Turquoise (#00acaf) - Used for primary headings, icons, and branding elements.
- **Secondary Color:** Orange (#f68b5c) - Used sparingly for Call-to-Actions (CTAs) and critical highlights.
- **Typography:** 
    - **Headings:** Noto Serif (or a high-quality Serif alternative) to match the elegance of the 'KISMET' logo.
    - **Body:** Manrope (or clean Sans-Serif) for readability.
- **Imagery Style:** Macro photography of raw commodities (coffee beans, cocoa pods, shelled nuts) to emphasize quality. Global logistics visuals (ships, maps) should be used subtly in the background.

## 2. Structure & Sections
### Hero Section
- **Headline:** Earth's Finest, Globally Delivered.
- **Subheadline:** Connecting the world's best growers with premium global markets. Specialist importers of Cocoa, Coffee, and Nuts.
- **CTA:** [Request a Quote] (Orange background).

### Product Categories (Grid)
- **Nuts:** From the Anatolian heartlands to the world.
- **Coffee:** Sourcing the finest Arabica and Robusta beans.
- **Cocoa:** Premium West African cocoa for the global chocolate industry.
- **Visuals:** High-resolution card-based layout with Turquoise hover effects.

### Trust & Logistics
- **Section Title:** Reliability at Every Coordinate.
- **Content:** Highlight supply chain stability, quality control certifications, and global reach.

## 3. Technical Notes for Implementation
- **Framework:** Tailwind CSS for styling.
- **Responsiveness:** Ensure the grid collapses gracefully on mobile devices.
- **Animations:** Use subtle fade-ins for sections and slight scale-ups for product cards.
- **Assets:** Use the SVG logos provided in the documentation for the header and footer to ensure crispness at any scale.
